NAMix changelog
https://github.com/mrgeneko/NAMix

Newest first.

08/27/2026 - v0.6.3
  - Fixed the plug-in's on-screen title, which still read "Anti-Static
    NAMix" (stale from before the product was renamed to "Anti-Static
    NAM") -- now matches the actual product name shown in the host's
    title bar.

08/27/2026 - v0.6.2
  - macOS release builds are now signed with a Developer ID Application
    certificate, hardened runtime enabled, and notarized/stapled by Apple
    (scripts/sign-notarize-macos.sh, run in CI before packaging). No more
    Gatekeeper "unidentified developer" warning on first launch. Verified
    signing locally against the real identity; notarization/stapling
    itself only runs in CI, where the App Store Connect API credentials
    live.

08/27/2026 - v0.6.1
  - Fixed macOS "Anti-Static NAM is damaged and can't be opened" error on
    first launch of a freshly downloaded release. The Standalone .app never
    received a real bundle-level code signature (only the linker's
    automatic ad-hoc stub on the raw executable, no sealed resources) --
    Gatekeeper rejects that outright as invalid once quarantined by a
    browser download, rather than showing the expected, dismissable
    "unidentified developer" prompt. makedist-macos.sh now explicitly
    codesigns the .app bundle before packaging, and packages with `ditto`
    instead of `zip` (which is documented to corrupt signed-bundle
    metadata). Verified locally: quarantined the packaged .app the same way
    a browser download does, confirmed `codesign --deep` reports valid and
    the app actually launches.

08/27/2026 - v0.6.0
  - Cross-platform build: macOS and Windows join Linux, sharing one
    CMakeLists.txt and one plug-in source tree. macOS also gains an Audio
    Unit build (needed for Logic Pro/GarageBand, which don't support VST3).
  - Bumped NeuralAmpModelerCore: fixed layer1x1_post_film being silently
    dropped under NONE/GATED gating, added a hand-unrolled Channels==9
    fast-path kernel, removed LoRA support (schema_version 2 models are now
    refused loudly instead of silently mis-parsed), and slowed the knob-
    smoothing time constant to reduce a DC-blocker transient on knob moves.
  - Replaced the muffinator_v4_optimal.param.nam demo download with 7
    models (large-muffin, british-800-preamp, cali-duo-reverb-85watt,
    dirty-hamster, clone-overdrive, special-bundle-overdrive-183-rock-
    channel, vinny-iii-drive) for more variety trying the parametric knobs.

07/20/2026 - v0.5.0
  - Parametric models: a model's own knobs and switches appear inline in the
    plug-in, driven by mrgeneko/NeuralAmpModelerCore's parametric (FiLM
    conditioning) support -- .nam files whose knobs respond live instead of
    being baked in at training time. Ordinary .nam models are unaffected and
    show no extra controls.
  - Renamed to Anti-Static NAM (`Anti-Static NAM.vst3`, standalone
    `Anti-Static NAM`), with its own bundle ID, so it installs alongside
    other NAM-based plug-ins rather than replacing them.
  - Parametric knob value readouts capped at two decimal places.
  - Added a real release pipeline: tagged pushes now build, run the unit
    test suite, package a `NAMix-<version>-linux-x86_64.tar.gz`, and publish
    a GitHub Release with the demo parametric model attached.
  - Added a unit test suite covering parametric-knob range validation,
    state-restore ordering, and the inline knob-row layout math.

06/12/2026 - v0.4.0
  - Renamed the plug-in to NAMix.
  - Packaging script (makedist-linux.sh) fixes.

06/06/2026 - v0.3.0
  - Added Devuan (Daedalus) to the supported build platforms.

06/05/2026 - v0.2.0
  - Standalone application, alongside the VST3 plug-in.
  - GUI fixes: level meters, the slimmable-model icon, tone dials, titlebar
    and tabs.

06/05/2026 - v0.1.0
  - Initial release: a Linux VST3 neural amp modeller built on JUCE, reusing
    NeuralAmpModelerCore and AudioDSPTools for the DSP core.
  - Noise gate, tone stack, and impulse-response loading.
